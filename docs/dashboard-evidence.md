# 第三期 M2：评测记录与离线审计复核

本轮新增评测记录、任务快照下载和离线逐步复核。所有页面沿用后台登录保护，后台仍没有操作执行、模型调用或配置编辑接口。

## 评测记录

侧栏“评测记录”从独立 `vey_eval` 读取已有实验，展示运行模式、数据版本、分组、提示／循环／评分版本、报告与实现哈希、已运行／未运行样本、通过数、请求次数、tokens、耗时和估算费用。没有记录的指标显示未知，费用 null 不解释为零。预设回放与真实模型运行分别标识，历史报告缺少评分版本时不推测版本。

样本支持通过／失败筛选与分页，失败原因和诊断轨迹保留原始内容，不通过后台重新评分或修改报告。每页 10 个样本，单个样本超过 200 KB 时明确不加载正文。实验列表每页最多 30 次运行。

公开案例已经分析过，因此属于已知回归，不是新的泛化证据；不同数据集、评分版本或运行模式不作直接分数对比。不把所有实验合并成一个“总准确率”。本轮只查询已有实验，不追加模型评测费用。

连接使用单独的 `vey_eval_reader`，只允许 SELECT 原有 runs/samples 两张表；不复用归档 writer，也不给核心或执行器实验库权限。运行默认只读，语句超时 5 秒。评测库未配置或暂不可用时评测页面报错，任务查询仍可使用。

管理员用专用实验库管理凭据文件初始化：

```bash
python scripts/bootstrap_eval_reader.py --admin-url-file /受限路径/实验库管理连接
```

脚本要求独立随机的至少 32 字符数据库密码，已存在的同名角色会拒绝覆盖。初始化不修改既有报告。在生产 `.env` 中新增 `VEY_DASHBOARD_EVAL_DATABASE_URL=postgresql+psycopg://vey_eval_reader:<独立密码>@<PG容器>:5432/vey_eval`，并把 `compose.dashboard-evals.yaml` 追加到原有 `COMPOSE_FILE` 后。只重建 dashboard 服务，无须重启核心、执行器或网关。

## 任务导出

任务详情里的“导出快照”下载 `vey-audit-<任务编号>.json`。文件带格式版本、导出时间、有限任务／事件／操作摘要和 SHA-256 校验。它不含原始聊天、会话身份、确认码、分页游标、容器 ID 列表或策略哈希；在已有脱敏基础上继续处理已知凭据字段、IPv4、邮箱和中国大陆手机号。普通错误代码保留供排查。

保留最多 100 条事件，是否截断写入文件。文件上限 1 MB、单文本字段最多 12000 字符；超出拒绝导出，不静默生成残缺文件。大小检查在脱敏前进行，避免对超大正文继续处理。

项目／服务别名、任务编号、时间和未知格式的敏感字符串仍可能存在，因此不能直接称为匿名数据集。分享前需要本人检查内容。下载文件由用户保管，服务器 30 天清理不会删除已下载副本。

## 离线复核

侧栏“离线复核”在浏览器本地读取文件，不上传。校验版本、大小、SHA-256、事件类型和递增顺序后，可逐步查看任务及每条事件。清除快照或退出后台会清除页面内的快照引用；不写入 localStorage。页面加载后，本地复核不需要 API 请求。

也可以在装有项目的电脑上运行：

```bash
python -m vey.replay vey-audit-任务编号.json --html review.html
```

该命令不读取生产配置或密钥，不连接网络，不调用模型或 Docker。它生成新的、无脚本的独立 HTML，已有输出文件会拒绝覆盖。HTML 转义全部记录并使用禁止网络资源的 CSP；用浏览器打开即可按事件展开。

SHA-256 只能检查内容一致性，不是签名，不能证明来源或结论正确。用户重新计算哈希后仍可以构造快照，因此快照绝不能成为执行指令。历史操作仅作为事实记录展示，没有“执行这一步”的能力。

审计缺少完整日志、原始 prompt 和部分失败工具尝试，复核不能复现模型推理、重算根因结论或保证 E 编号对应每一条工具事件。此功能是按顺序查看已记录证据，不等同于完整 Agent 仿真。

## 验证范围

新增真实 PostgreSQL 只读角色／分页／失败筛选测试，HTTP 鉴权／导出测试，快照脱敏／篡改／顺序／大小测试，禁用网络的 Python 离线 HTML 测试。JavaScript 使用独立的无浏览器契约测试验证逐步复核、校验拒绝、退出清理和零网络请求；该测试不等同于浏览器布局验收。

本轮浏览器自动化命令被自动审批拒绝（只返回 blocked by policy）；应用内浏览器工具又因找不到本地内核资产路径而无法启动。因此本轮没有完成新的真实浏览器点击和布局验收，不沿用 M1 的截图宣称 M2 已通过。生产 HTTP 验收另外记录。
