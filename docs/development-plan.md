# 第一期开发计划与进度

日期：2026-09-25。用户已授权进入第一期开发。

部署约束：复用 Ubuntu 上已有的 PostgreSQL 容器，默认不启动新的数据库；模型使用 DeepSeek。本地开发不连接用户服务器，不修改现有业务数据库。

## 实施顺序

1. 项目骨架、配置校验、数据库迁移与最小权限初始化脚本。
2. 独立执行器：目标白名单、受保护清单、固定只读工具、一次性确认、执行记录。
3. 核心服务：企微验签解密、消息去重、15 分钟会话、持久化任务和回复队列。
4. DeepSeek 适配、确定性控制指令、5 次调用／60 秒有限排查。
5. 隔离测试、异常和并发验证、部署与备份恢复说明。

## 完成标准

以 requirements.md 的第一期验收表为准。单元测试、真实 PostgreSQL 集成测试和 Docker／企微／DeepSeek 真实环境验收分别记录，模拟测试不替代外部服务验收。

## 已实现

- Python 项目、锁定依赖、配置示例、双服务 Compose、GitHub Actions 检查配置。
- FastAPI 企微入口：验签、解密、本人／应用验证、重复消息去重；默认关闭的认证调试入口。
- PostgreSQL 七张表、冻结的首版迁移、独立角色初始化。核心与执行器通过 Unix socket + 共享令牌通信；核心无 Docker socket。
- 只读工具、日志限额与分页、保护清单、确认消费、目标快照复核、串行修改、操作后状态和可选业务健康检查。
- DeepSeek JSON 模式适配、Pydantic 输出校验、可替换 IntentRouter、确定性控制指令、有限排查及证据摘要。
- 会话清理、审计清理、持久化 outbox、未知结果保护与管理员核对脚本。
- [README](../README.md) 和 [部署、备份恢复手册](deployment.md)。

## 第一期剩余工作

当前交付是可运行核心的本地实现，不将第一期标为全部验收完成：

1. 在隔离 Ubuntu／Docker 环境构建镜像，验证宿主机指标、真实容器日志与启停；核实共享 socket 和 secret 文件权限。
2. 确定现有 PG 版本、容器／网络、允许管理的服务、实际依赖保护清单和健康地址，再做最小权限连接测试。
3. 配置 DeepSeek 密钥和企微应用、完成真实端到端流程；域名未就绪时先用认证调试入口验证。
4. 日志目前以脱敏原文分页返回；自动摘要／展开交互、手机端中文结果格式仍需完善。超出 5000 行／1 MB 内部窗口时要求缩小时间范围，暂不自动遍历全部历史。
5. 系统概况当前提供已映射文件系统及进程内存排行；全部目标挂载点、容器跨服务排行和可配置异常阈值还需补齐并验收。
6. 确定生产审计容量预算、磁盘告警接入、异机备份位置和保留策略；本地恢复演练不能代替真实部署恢复演练。
