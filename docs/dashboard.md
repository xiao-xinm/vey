# 管理后台

入口为 `https://<你的域名>/admin/`。后台独立于聊天工作进程运行，读取现有审计，不能发送消息、调用模型或执行 Docker 操作。

本文包含 [任务查询](#功能与数据范围)、[评测与离线复核](#evidence)、[服务配置与回滚](#configuration)。默认后台数据账号只读；启用配置管理后，另外只读挂载执行器 socket 目录及独立管理令牌，仍不持有运维执行令牌或 Docker socket。

## 功能与数据范围

- 当前保留任务的状态计数、状态筛选和游标分页，每次最多 50 条。
- 任务结果摘要、创建至最后更新的时长、已记录的工具／模型调用次数。
- 事件时间线，查看工具的有限日志摘要、模型版本／耗时／用量元数据、结构化诊断与证据引用。
- 操作状态及有效期；待确认记录超过时间后明确显示已超过有效期，不展示确认码。

数据来自已有记录，不长期保存新的对话或日志副本。每个任务最多展示前 100 条事件，超出明确标记截断。工具事件只在成功返回后记录，因此“已记录工具次数”不一定涵盖所有失败尝试。事件展示编号不是诊断 E 编号，不虚构两者的映射。完整日志、模型内部思维链和未记录的指标无法通过后台恢复。

列表按创建时间和 ID 倒序做游标分页；游标对应任务已被清理时要求刷新。概览与列表是分别查询的，运行中的数据会变化。状态计数是当前保留范围，既不代表全生命周期累计，也不代表诊断正确率。创建至最后更新包含排队时间。

## 身份与权限

登录口令必须为独立随机的至少 32 字符字符串，通过 `VEY_DASHBOARD_PASSWORD_FILE` 挂载。不复用 SSH、企微、模型或数据库密码。浏览器仅持有随机会话 Cookie，设置 `Secure`、`HttpOnly`、`SameSite=Strict` 及 `__Host-` 前缀，不存储在 localStorage 或 URL 中。

会话闲置 15 分钟失效，最长 8 小时；退出、重新登录替换原会话及服务重启均会使相应会话失效。页面不自动轮询，刷新／查看任务属于活动。单进程最多 8 个会话，新登录超过上限会淘汰最旧会话。服务全局每分钟最多 10 次登录尝试，不信任客户端转发 IP；可能因外部大量尝试暂时限制合法登录，但不影响企微工作进程。

登录、退出校验精确 Origin；页面使用 CSP、禁止嵌入、no-store 及文本 DOM 渲染。原始日志中的 HTML 不会作为网页执行。口令仅保存在受限服务器文件中，轮换后需重建后台服务；当前没有多用户、SSO、找回密码或登录历史持久化。

三个 `vey_dashboard` 视图投影任务、事件和操作记录，隐藏原始会话字段与操作确认码；应用输出另外执行脱敏与游标过滤。视图由管理员拥有，运行账号仅有 SELECT 权限，无法直接读原始表或修改视图；`default_transaction_read_only` 和 5 秒语句超时是额外限制。默认后台不挂载 Docker socket、执行器 socket、核心密钥、模型密钥或企微密钥；启用配置管理时，仅额外挂载受限的执行器 socket 目录及独立管理令牌。已有审计里的自由文本脱敏不能保证识别所有未知格式的敏感数据，因此入口只面向本人。

## 安装

先完成原有数据库迁移和 HTTPS 部署。管理员连接专用 `vey` 数据库，使用交互式初始化脚本：

```bash
python scripts/bootstrap_dashboard.py
```

脚本读取 `VEY_MIGRATION_DATABASE_URL`，提示输入一个独立随机数据库密码，只新建 `vey_dashboard` schema、三个视图和同名角色；不改原有业务表。如果角色／schema 已存在会拒绝覆盖，需要管理员先检查。初始化事务失败会回滚。

在生产 `.env` 配置：

```text
VEY_DASHBOARD_DATABASE_URL=postgresql+psycopg://vey_dashboard:<独立数据库密码>@<PG容器>:5432/vey
VEY_DASHBOARD_IMAGE=vey-agent:<本次冻结版本>
COMPOSE_FILE=compose.yaml:compose.https.yaml:compose.minio.yaml:compose.dashboard.yaml
```

未使用 MinIO 时从叠加文件列表中去掉该项。生成独立后台登录口令至 `secrets/dashboard_password`，设置 root:10000、0640，目录仅管理员可写。容器以 UID 10004 运行。已有 `.env`、配置、密钥不得加入 Git。

```bash
docker compose --profile https up -d --no-deps --wait dashboard
docker compose --profile https up -d --no-deps --wait https-gateway
```

网关只新增 `/admin/` 路由，没有发布后台宿主机端口。新增挂载需要重建网关，会短暂影响 HTTPS 入口；核心与执行器无须重启。`/health/ready` 仅供 Docker 内部探测，不由网关代理。生产需要 HTTPS；HTTP 仅允许 localhost/127.0.0.1 本地开发 origin，Cookie 仍设置 Secure。

在 SSH 终端读取后台登录口令（不要发到聊天或截图）：

```bash
sudo cat /opt/vey/secrets/dashboard_password
```

## 关闭与回滚

先从 Compose 叠加文件移除 `compose.dashboard.yaml` 并重建网关，验证企微回调和 MinIO 仍正常，再停止／删除单独的 dashboard 容器。不执行整个 Vey 项目的 `down`。只读视图可保留，或由管理员在确认无连接后撤销其角色登录、删除视图／schema 与专用角色；不恢复旧业务数据库覆盖新的任务审计。

后台视图不是运行期自动迁移的一部分。恢复数据库或变更底层 schema 后，需要核对视图及独立角色权限，再启动后台；不能通过授予原始表全部权限解决错误。

## 评测记录与离线审计复核


评测、任务快照和离线复核页面沿用后台登录保护，不调用模型或运维工具。服务配置另由本文的独立管理接口处理。

### 评测记录

侧栏“评测记录”从独立 `vey_eval` 读取已有实验，展示运行模式、数据版本、分组、提示／循环／评分版本、报告与实现哈希、已运行／未运行样本、通过数、请求次数、tokens、耗时和估算费用。没有记录的指标显示未知，费用 null 不解释为零。预设回放与真实模型运行分别标识，历史报告缺少评分版本时不推测版本。

样本支持通过／失败筛选与分页，失败原因和诊断轨迹保留原始内容，不通过后台重新评分或修改报告。每页 10 个样本，单个样本超过 200 KB 时明确不加载正文。实验列表每页最多 30 次运行。

公开案例已经分析过，因此属于已知回归，不是新的泛化证据；不同数据集、评分版本或运行模式不作直接分数对比。不把所有实验合并成一个“总准确率”。本轮只查询已有实验，不追加模型评测费用。

连接使用单独的 `vey_eval_reader`，只允许 SELECT 原有 runs/samples 两张表；不复用归档 writer，也不给核心或执行器实验库权限。运行默认只读，语句超时 5 秒。评测库未配置或暂不可用时评测页面报错，任务查询仍可使用。

管理员用专用实验库管理凭据文件初始化：

```bash
python scripts/bootstrap_eval_reader.py --admin-url-file /受限路径/实验库管理连接
```

脚本要求独立随机的至少 32 字符数据库密码，已存在的同名角色会拒绝覆盖。初始化不修改既有报告。在生产 `.env` 中新增 `VEY_DASHBOARD_EVAL_DATABASE_URL=postgresql+psycopg://vey_eval_reader:<独立密码>@<PG容器>:5432/vey_eval`，并把 `compose.dashboard-evals.yaml` 追加到原有 `COMPOSE_FILE` 后。只重建 dashboard 服务，无须重启核心、执行器或网关。

### 任务导出

任务详情里的“导出快照”下载 `vey-audit-<任务编号>.json`。文件带格式版本、导出时间、有限任务／事件／操作摘要和 SHA-256 校验。它不含原始聊天、会话身份、确认码、分页游标、容器 ID 列表或策略哈希；在已有脱敏基础上继续处理已知凭据字段、IPv4、邮箱和中国大陆手机号。普通错误代码保留供排查。

保留最多 100 条事件，是否截断写入文件。文件上限 1 MB、单文本字段最多 12000 字符；超出拒绝导出，不静默生成残缺文件。大小检查在脱敏前进行，避免对超大正文继续处理。

项目／服务别名、任务编号、时间和未知格式的敏感字符串仍可能存在，因此不能直接称为匿名数据集。分享前需要本人检查内容。下载文件由用户保管，服务器 30 天清理不会删除已下载副本。

### 离线复核

侧栏“离线复核”在浏览器本地读取文件，不上传。校验版本、大小、SHA-256、事件类型和递增顺序后，可逐步查看任务及每条事件。清除快照或退出后台会清除页面内的快照引用；不写入 localStorage。页面加载后，本地复核不需要 API 请求。

也可以在装有项目的电脑上运行：

```bash
python -m vey.replay vey-audit-任务编号.json --html review.html
```

该命令不读取生产配置或密钥，不连接网络，不调用模型或 Docker。它生成新的、无脚本的独立 HTML，已有输出文件会拒绝覆盖。HTML 转义全部记录并使用禁止网络资源的 CSP；用浏览器打开即可按事件展开。

SHA-256 只能检查内容一致性，不是签名，不能证明来源或结论正确。用户重新计算哈希后仍可以构造快照，因此快照绝不能成为执行指令。历史操作仅作为事实记录展示，没有“执行这一步”的能力。

审计缺少完整日志、原始 prompt 和部分失败工具尝试，复核不能复现模型推理、重算根因结论或保证 E 编号对应每一条工具事件。此功能是按顺序查看已记录证据，不等同于完整 Agent 仿真。

### 验证范围

新增真实 PostgreSQL 只读角色／分页／失败筛选测试，HTTP 鉴权／导出测试，快照脱敏／篡改／顺序／大小测试，禁用网络的 Python 离线 HTML 测试。JavaScript 使用独立的无浏览器契约测试验证逐步复核、校验拒绝、退出清理和零网络请求；该测试不等同于浏览器布局验收。

最新浏览器验收缺口统一记录在 [V1 清单](v1-delivery.md)，接口或契约测试不能替代真实浏览器验收。

## 服务配置管理、版本审计与回滚


本阶段将服务登记迁入执行器管理的版本表，后台提供编辑、校验、差异确认和回滚草稿。范围为已有 Compose 服务的 key、别名、保护标志和健康检查 URL；不提供容器部署、任意命令、密钥编辑或操作确认入口。

### 使用

登录后台，打开“服务配置”。修改或添加登记，填写原因，点击“校验并查看差异”；核对新增／删除／修改内容、服务顺序及缺失容器提示，勾选确认后发布。每次操作最多 50 个服务、每服务 8 个别名，请求最多 64 KiB。新增项必须匹配真实 Compose 项目／服务标签，已有历史登记项未匹配时保留并警告，不假装它已部署。

健康检查允许 HTTP(S)，不允许凭据、查询参数、URL 片段及无效端口；保存或校验不会访问该 URL。真正健康检查仍只由固定查询工具执行。健康地址和别名会保存在配置历史中，请勿填入秘密信息。

校验结果有效 5 分钟，绑定当前版本、完整候选内容、原因、回滚来源和容器 ID。编辑、过期、并发发布或容器替换都会使原校验无效。退出登录清除本地草稿与待发布凭据；异步返回不能重新激活旧草稿。发布失败或响应丢失时先刷新核对生效版本，不自动重试。

历史区展示最近 100 个版本（数据库保留完整历史）；回滚先载入历史服务列表，再经过同样的校验与确认。回滚产生新版本，保留原始版本及原因，不倒退版本 ID。相同内容不重复发布。

### 安全与并发

- `config/vey.toml` 仍为 root 维护的只读保护基线。owner、自身项目、保护项目、固定容器 ID、阈值均不开放编辑；基线内受保护服务和自身项目登记项不能删除或解除保护。后台可为其他服务增加保护；基线以外的可编辑标志可以调整。
- 基线哈希保存在状态表中。手工改文件后与已初始化状态不一致会拒绝使用配置；基线扩充由管理员另行评审及迁移。
- 后台数据库账号仍为只读。配置写入通过执行器 Unix socket 的独立管理令牌进行，只开放读取配置、校验、发布三个接口。管理令牌不能调用运维接口，核心的运维令牌不能调用管理接口；浏览器拿不到服务间令牌。
- 核心在每个新任务开始取得当前策略快照；读取和准备修改均携带版本。若模型等待期间版本变化，执行器拒绝旧请求，用户需重新发起。固定基线身份不变，已有操作确认仍须在企微完成。
- 每次发布／回滚原子地插入版本、切换生效指针、取消全部 pending 确认。确认哈希含版本 ID，因此内容回滚也不能恢复旧授权。旧会话仍保留 15 分钟期限，旧游标是否可用还受当前服务配置检查。
- 查询／准备／确认使用 PostgreSQL 事务级共享咨询锁；发布使用同一个键的排他锁，确认持锁直到 Docker 调用及结果持久化结束。等待锁超过 5 秒则发布失败，不绕过锁。配置锁使用独立连接池，避免占满操作写入连接造成互相等待。[PostgreSQL 咨询锁](https://www.postgresql.org/docs/16/functions-admin.html#FUNCTIONS-ADVISORY-LOCKS)
- executing 或 unknown 操作存在时拒绝发布；先按现有人工核对流程处理。配置发布不替用户清除未知锁，也不能撤销已经发生的 Docker 操作。
- 版本表拒绝 UPDATE／DELETE，并撤销运行角色的 UPDATE／DELETE／TRUNCATE 权限；记录父版本、服务内容、原因、时间和回滚来源。成功发布就是持久审计，拒绝的请求不生成版本。当前为单一后台管理员，不声称能区分多个自然人，也不声称抵抗数据库管理员或执行器整体失陷。

### 部署

先备份并演练恢复，确认无活动任务／操作，保存旧核心、执行器、后台镜像和 `.env`。短暂停止核心与执行器，使用迁移所有者执行 `alembic upgrade head`（新增 `0003`）；运行角色不能自行建表。迁移只新增 `vey_exec.policy_versions`、`policy_state` 和历史防改触发器，保留原有数据。

管理员生成独立随机 `secrets/configuration_token`（root:10000 / 0640），不要复制运维令牌。保持目录仅管理员可写。在现有 `COMPOSE_FILE` 追加 `compose.configuration.yaml`，设置 `VEY_CONFIGURATION_IMAGE=vey-agent:<冻结发布版本>`，保留已有所有叠加项。若已经使用 `compose.jev.yaml`，配置管理文件必须排在它之前，Jev 文件仍放最后，避免覆盖当前核心镜像与路由设置。

```bash
docker compose up -d --no-deps --force-recreate --wait ops-executor
docker compose up -d --no-deps --force-recreate --wait agent-core dashboard
```

执行器首次启动从文件基线初始化一个版本；以后从数据库读取，发布无需重启。后台仅新增只读 runtime 目录挂载及配置管理令牌，不挂载 Docker socket，也不持有管理员数据库连接。核心／执行器需同时升级，旧客户端未传版本时会拒绝读取／准备请求。

代码回退前停止核心与执行器，核对最新配置与基线差异，暂停配置入口；不能直接启动只懂文件配置的旧执行器并忽略已发布的新保护规则。若需要旧版本运行，先由管理员把经审核的有效服务配置合入只读文件并重建容器，再恢复服务；配置历史表保留，不 downgrade、不倒灌旧数据库。备份恢复应同时覆盖数据库和匹配的文件基线。

自动化验证包括真实 PG 版本迁移、保护约束、预览篡改／过期／容器替换、旧确认与回滚、未知操作阻断、并发锁、管理令牌隔离、CSRF、体积限制、前端草稿失效。真实浏览器点击／布局验收受当前 CUA 超时影响，不能用接口检查替代。
