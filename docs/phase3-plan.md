后台使用 FastAPI 加原生 HTML/CSS/JavaScript，随现有 Python 镜像打包，独立 Compose 服务运行。配置表单已独立为 configuration.js，沿用原生页面与显式草稿状态，不引入前端构建链。

后台使用 `vey_dashboard` 数据库角色，只授权三个投影视图；配置管理另有独立令牌，通过执行器的限定接口发布，不持有运维执行令牌、模型或企微凭据。登录使用独立随机口令，HTTPS 安全 Cookie，服务端内存会话；单进程运行，重启会话失效。具体部署与限制见[后台手册](dashboard.md)。
