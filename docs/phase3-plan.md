# 第三期：管理后台与可维护性

2026-10-06 开始，M1 已部署并验收，见[验收记录](dashboard-acceptance.md)。M2 功能已上线，接口、权限与离线契约已验证，真实浏览器验收待工具恢复后补做，见[M2 记录](dashboard-evidence-acceptance.md)。沿用现有核心、执行器和独立评测库，Jev 继续延期。

| 里程碑 | 范围 | 验收要求 |
| --- | --- | --- |
| M1：只读任务工作台（已交付） | 独立登录、任务状态筛选与分页、结果摘要、事件时间线、操作有效期 | 独立进程和只读数据库角色；未登录不可读取；不暴露原始会话、确认码或执行入口；106 项测试、真实 PG、浏览器与生产 HTTPS 验证 |
| M2：评测与离线复核（已上线，浏览器验收待补） | 只读展示独立实验库；任务导出、脱敏复核与离线回放 | 111 项测试及 JavaScript 契约通过；生产确认独立只读角色、13 次／312 样本可查询、快照导出可离线校验 |
| M3：配置与运维完善 | 服务配置版本及审计、不可移除的核心保护对象、容量与备份演练、演示材料 | 配置变更经过校验与回滚；异地存储需确定目的地；证据与演示可复现 |

M1 使用 FastAPI 加原生 HTML/CSS/JavaScript，随现有 Python 镜像打包，独立 Compose 服务运行。当前是单页只读查询，不引入前端构建链和额外权限框架。后续配置编辑增加时再评估组件化和表单状态管理。

后台使用新的 `vey_dashboard` 数据库角色，只授权三个投影视图；不持有核心、执行器、模型或企微凭据。登录使用独立随机口令，HTTPS 安全 Cookie，服务端内存会话；单进程运行，重启会话失效。具体部署与限制见[后台手册](dashboard.md)。

M3 运维部分已推进本机备份、隔离恢复和容量报告，见[运维手册](operations-recovery.md)及[验收记录](operations-recovery-acceptance.md)。按用户 2026-10-07 的选择，异地位置稍后确定。

整个第三期尚未完成。配置编辑、定时／异地备份与演示视频仍属于 M3；M2 和新增容量页的真实浏览器点击与布局验收尚待工具恢复后补做。
