# Vey 六分钟演示与录制脚本

2026-10-08 更新。此文是准备完成的分镜和台词，**完整视频尚未录制**。此前真实客户端查询／确认重启的证据见[聊天验收](evidence/history.md#phase1-chat-acceptance)；不能把接口脚本或架构图称为客户端实录。

## 录制前准备

1. 打开[结构图](assets/vey-architecture.png)、企微应用和本人管理后台。只录目标窗口，隐藏联系方式、企业标识、登录口令、Key、真实日志正文等私人数据；不要打开服务器秘密目录。
2. 确认服务健康，演示期间没有其他用户任务或部署。修改演示只使用已登记的 `vey-acceptance/web`，别名“测试服务”；先核对后台登记及保护状态。没有登记就先准备，不把失败剪辑成成功。
3. 如果需要重启演示，由管理员在服务器启动现有测试 fixture：

```bash
cd /opt/vey
sudo docker compose -f tests/fixtures/acceptance.compose.yaml up -d
```

它是独立测试项目，不对 PG、Redis、Agent 或个人业务做启停示范。不要运行包含消息发送、启停和清理的综合验收脚本来“只生成日志”。日志样本不足时如实展示“无更多日志”，不要伪造分页结果。

## 演示结束

保存任务编号及需要的脱敏证据，发送 `清空上下文`。确认独立测试项目无人使用后，清理本次创建的 fixture：

```bash
cd /opt/vey
sudo docker compose -f tests/fixtures/acceptance.compose.yaml down
```

退出后台，删除本地不需要保留的私密录屏素材。不要清理业务容器或扩大为 Docker 全局 prune。

## 发布视频前的复核

- [ ] 显示当前日期与演示环境，避免把旧截图当成最新状态。
- [ ] 明确查询、诊断、等待确认和执行后四个不同阶段。
- [ ] 确认前测试容器没有重启；确认后确实重启且可查询。
- [ ] 快照离线复核能前进／后退，退出后清除状态。
- [ ] 核心保护项不能解除；没有展示秘密文件、真实确认码的长期复用或任意命令能力。
- [ ] 评测明确是 18 个已知案例各重复两次，不说“生产准确率 100%”。
- [ ] 保留边界：Docker 权限仍高、模型语义可能出错、外部副作用无法与 PG 原子提交。
- [ ] 备份、录屏和浏览器验收的状态与[交付清单](v1-delivery.md)一致。

当前浏览器验收工具超时，上述新增页面交互与录屏项目不能自动勾选。架构讲解稿及面试问答见[面试材料](interview-guide.md)。
